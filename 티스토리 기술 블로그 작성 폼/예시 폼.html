리소스 그룹 생성
Azure CLI를 사용하여 리소스 그룹을 생성합니다. 지역은 koreacentral을 권장합니다.
bash / Azure CLI 
# 변수 설정
RESOURCE_GROUP="rg-demo-001"
LOCATION="koreacentral"

# 리소스 그룹 생성
$ az group create \
    --name $RESOURCE_GROUP \
    --location $LOCATION
